# Python style

## Python style comparisons none
Compare with None using is and is not. Use truthiness checks only when None and empty values mean the same thing.

## Logging debug print statements
Use the logging module with levels. Remove print calls and debugger statements before merging.

## TODO comments issues tracking
Open an issue for every TODO or FIXME and reference its number in the comment.

## Functions and naming
Keep functions short, use descriptive snake_case names and add type hints to public functions.
